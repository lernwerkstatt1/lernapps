So ist der Code aufgebaut

Aufbau
EF1-, dann ein Zeichen je Kapitel, dann - und zwei Prüfzeichen.
Kapitelzeichen
Wert v (Basis 36, 0 bis z) = 3 · q + o. q ist der Anteil der beim ersten Versuch richtig gelösten geschlossenen Aufgaben in Zehnteln (0 bis 10, gerundet); q = 11 heißt „keine geschlossene Aufgabe bearbeitet“. o beschreibt die offenen Aufgaben: 0 keine, 1 teilweise, 2 alle bearbeitet. Übersprungene Aufgaben zählen als nicht richtig.
Prüfzeichen
Summe aus Position · Wert über alle Kapitelzeichen (Position ab 1), modulo 1296, als zwei Zeichen zur Basis 36. Sie fangen Tippfehler ab und verhindern keinen Betrug. Die App ist eine Übung.
Farben und Noten
Rot unter 45 %, Orange ab 45 %, Gelb ab 55 %, Gelbgrün ab 70 %, Grün ab 85 %. Die Noten folgen dem in der Oberstufe üblichen Schlüssel (ab 95 % 1+, ab 45 % 4, unter 20 % 6). Da der Code die Anteile auf Zehntel rundet, ist die Note hier nur eine Orientierung; die Gesamtnote ist der Mittelwert der bearbeiteten Kapitel.
Grundlage
Der Code fasst das jeweils letzte Ergebnis jeder Aufgabe zusammen, die auf dem Gerät bearbeitet wurde. Offene Aufgaben gelten als bearbeitet, wenn mindestens 20 Zeichen geschrieben wurden; sie werden nie als richtig oder falsch gewertet.
